# Narendra R Giriyappanavar - Personal Portfolio

Welcome to the source code of my personal portfolio website! 🚀

## 🎨 About The Design

This portfolio was built with a unique, interactive **"Sketchbook" theme** using pure HTML, CSS, and Vanilla JavaScript. The goal was to create an experience that feels personal, creative, and highly responsive.

### Key Features:
- **Custom Light & Dark Mode:** Switch seamlessly between a bright "Graph Paper" theme and a sleek dark "Blueprint" theme.
- **Cinematic Loader:** A custom, fully animated loader that provides a "dive in" effect when the site finishes loading.
- **Micro-Interactions:** Subtle hover effects, smooth scroll animations via Intersection Observer, and a custom pencil cursor for a complete sketchbook feel.
- **Fully Responsive:** Optimized for desktops, tablets, and mobile phones.

## 🛠 Tech Stack

- **HTML5** for semantic structure
- **CSS3** (Vanilla) for advanced layouts, CSS variables (theming), animations, and transitions
- **Vanilla JavaScript** for DOM manipulation, theme toggling, and scroll effects
